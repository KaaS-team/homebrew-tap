# homebrew-tap

The Homebrew tap for [KaaS Factory](https://github.com/KaaS-team/KaaS-factory).

**Status: no formula yet.** `brew install KaaS-team/tap/factory` does not work until the first release ships binaries. Until then, use the [curl or npm installer](https://github.com/KaaS-team/factory-install).

## When it is published

```sh
brew install KaaS-team/tap/factory
```

The formula will point at the release assets of KaaS Factory and be bumped automatically on each release.
